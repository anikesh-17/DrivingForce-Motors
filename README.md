# 🚗 DrivingForce Motors

DrivingForce Motors is a full-stack automotive dealership management platform built with a Salesforce-first architecture.

## 🚀 Project Overview

The platform connects a public automotive website with Salesforce CRM to manage the complete customer journey:

**Vehicle Discovery → Enquiry → Lead → Customer → Test Drive → Opportunity → Sale**

## 🏗️ Architecture

```text
Customer
   │
   ▼
React Frontend
   │
   ▼
Node.js + Express Backend
   │
   ├──────────────► Salesforce CRM
   │
   └──────────────► Cloudinary
```
